# E2 Travel AI Agent

A Tier-1 AI Support Agent and troubleshooting assistant designed for the **E2 Travel Software (E2 Solutions)** used across the U.S. Mission and Department of State (DOS) operations globally (covering over 200 posts).

---

## 🚀 Overview
This project serves as an intelligent prototype and support automation tool to help IT analysts, travel administrators, and embassy personnel navigate travel authorizations (TA), expense reporting workflows, policy compliance, and software troubleshooting.

## 🛠️ Key Features
- **E2 Travel Policy Guidance:** Answers complex questions regarding U.S. government travel regulations, per diem calculations, and ticketing procedures.
- **Incident Analysis & Troubleshooting:** Diagnoses software issues, data synchronization errors, and user profile management, offering step-by-step resolution paths.
- **Workflow Automation & SOPs:** Assists in reviewing software changes, streamlining administrative tasks, and referencing standard operating procedures.
- **Modern Tech Stack:** Built with TypeScript, Node.js (`server.ts`), Vite, and powered by Gemini AI models.

## 📁 Project Structure
- `src/` - Source code and application components.
- `server.ts` - Backend server handling API requests and AI integration.
- `package.json` - Project dependencies and scripts.
- `metadata.json` & `tsconfig.json` - Configuration and metadata files.
